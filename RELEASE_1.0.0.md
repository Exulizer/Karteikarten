## Kartenbox 1.0.0

Karteikarten als eine HTML-Datei. Offline, ohne Server, ohne Konto.

**So geht's:** `kartenbox-1.0.0.zip` laden, entpacken, `karteikarten.html` öffnen.

**Enthalten**
- Karten im Fächer, Fächer, Lernstand, Demo
- Gewusst / Nochmal mit Ablage, Anheften, Marker
- Karten speichern, laden und teilen
- Hilfe mit FAQ und Datenschutz
- Update-Hinweis (abschaltbar): Desktop aktualisiert per Klick, Handy bekommt nur den Link
